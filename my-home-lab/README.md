# My Home Lab — Proxmox sortable table

Это версия текущего сайта с сортировкой таблицы VM/LXC.

На странице Proxmox можно нажимать заголовки:
- ID
- Имя
- Тип
- Состояние
- Ресурсы / CPU

Первое нажатие сортирует по возрастанию, повторное — по убыванию.
По умолчанию сохраняется прежняя сортировка: RUNNING сверху, затем STOPPED, внутри — по ID.

Proxmox agent и API не изменяются.
